# 라면질문 점프! 설치 안내

학생 태블릿과 교사 컴퓨터(전자칠판)를 실시간으로 연결하는 '라면질문 만들기' 수업용 웹앱이에요.
깃허브 페이지(화면)와 Firebase(저장)를 연결하고, 처음 한 번만 설정하면 돼요. 20분 정도 걸려요.
두 서비스 모두 무료이고, 카드를 등록하지 않아서 요금이 나갈 일이 없어요.

## 들어 있는 파일

| 파일 | 하는 일 |
|---|---|
| index.html | 학생 화면 (태블릿) |
| teacher.html | 교사 화면 (전자칠판) — 소리는 여기서만 나요 |
| common.js, common.css | 두 화면이 함께 쓰는 코드와 디자인, 배경음악·효과음 |
| config.js | Firebase 연결 정보 (2단계에서 직접 채워요) |
| firestore.rules | Firebase 보안 규칙 (3단계에서 붙여 넣어요) |

> 파일을 받자마자 `teacher.html`과 `index.html`을 컴퓨터에서 열어 보면 **체험 모드**로 움직여요.
> 같은 컴퓨터의 브라우저 창 두 개(교사·학생)끼리만 연결되니, 미리 흐름을 확인해 볼 때 쓰세요.

---

## 1단계. 깃허브에 새 저장소 만들기

지금 쓰시는 `class` 저장소와는 **따로** 만들어요.

1. https://github.com 에 로그인해요.
2. 오른쪽 위 **+** → **New repository** 를 눌러요.
3. Repository name에 `ramen` 이라고 적어요. (다른 영어 이름도 괜찮아요)
4. **Public** 을 고르고 **Create repository** 를 눌러요.
5. 다음 화면에서 **uploading an existing file** 을 눌러요.
6. 파일 7개(README.md 포함)를 모두 끌어다 놓고 **Commit changes** 를 눌러요.
7. 저장소 위쪽 **Settings** → 왼쪽 **Pages** 로 가요.
8. Source는 **Deploy from a branch**, Branch는 **main** / **(root)** 로 고르고 **Save** 를 눌러요.
9. 1~2분 뒤 위쪽에 주소가 나와요. 예: `https://gjue2020-dotcom.github.io/ramen/`
   - 이 주소가 **학생 주소**예요.
   - 주소 끝에 `teacher.html` 을 붙이면 **교사 주소**예요. 예: `https://gjue2020-dotcom.github.io/ramen/teacher.html`
   - 지금 열면 "체험 모드"라고 나오는 게 정상이에요.

## 2단계. 새 Firebase 프로젝트 만들고 연결 정보 넣기

지금 쓰시는 학급 기록장 프로젝트와 **따로** 만들어요. (학생들이 로그인 없이 쓰는 앱이라, 학급 기록과 섞지 않는 게 안전해요)

1. https://console.firebase.google.com 에 구글 계정으로 들어가요.
2. **프로젝트 만들기**(또는 **새 프로젝트**) → 이름 `ramen` 입력 → Google 애널리틱스는 꺼도 돼요 → 만들기.
3. 프로젝트 첫 화면에서 **웹 아이콘 `</>`** 을 눌러 웹 앱을 추가해요.
   - 앱 닉네임: 아무거나 (예: `라면질문`)
   - "Firebase 호스팅도 설정"은 체크하지 않아요.
4. **앱 등록** 을 누르면 `firebaseConfig = { apiKey: ... }` 코드가 보여요. 이 화면을 열어 둬요.
5. 깃허브 `ramen` 저장소에서 **config.js** 를 누르고, 오른쪽 위 **연필(Edit)** 버튼을 눌러요.
6. `"여기에"` 자리 6곳에 Firebase 화면의 값을 하나씩 옮겨 적어요. 따옴표는 그대로 두세요.

   ```js
   window.FIREBASE_CONFIG = {
     apiKey: "AIza...",
     authDomain: "ramen-xxxx.firebaseapp.com",
     projectId: "ramen-xxxx",
     storageBucket: "ramen-xxxx.firebasestorage.app",
     messagingSenderId: "1234567890",
     appId: "1:1234567890:web:abcd..."
   };
   ```
   (Firebase 화면에 `measurementId` 가 더 있으면 같이 넣어도, 빼도 괜찮아요.)
7. **Commit changes** 를 눌러 저장해요.

## 3단계. 저장소(데이터베이스) 만들고 보안 규칙 넣기

1. Firebase 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**.
2. 위치는 **asia-northeast3 (서울)** 을 골라요. 나중에 바꿀 수 없어요.
3. **프로덕션 모드에서 시작** 을 고르고 만들기.
4. 위쪽 **규칙** 탭으로 가서, 들어 있는 내용을 모두 지우고 `firestore.rules` 파일 내용을 붙여 넣은 뒤 **게시** 를 눌러요.

이번 앱은 로그인을 쓰지 않아서 **Authentication(로그인) 설정은 하지 않아도 돼요.**

## 4단계. 확인하기

1. 컴퓨터에서 **교사 주소**를 열어요. 위에 "체험 모드" 노란 띠가 **없으면** 연결된 거예요.
   - 아직 보이면 1~2분 기다린 뒤 새로고침(Ctrl+F5) 해 보세요.
2. 휴대폰으로 **학생 주소**를 열고 번호를 눌러요.
3. 교사 화면에서 **게임 시작** → 휴대폰에서 질문을 보내 보세요. 교사 화면에 "띠링" 소리와 함께 질문이 뜨면 성공이에요.
4. 시험해 본 기록은 **지난 기록**에 남아요. (기록은 지울 수 없게 막아 두었어요. 시험 기록이 신경 쓰이면 Firebase 화면 Firestore Database에서 직접 지울 수 있어요)

## 수업에서 쓰기

**준비**: 전자칠판에서 교사 주소, 학생 태블릿에서 학생 주소를 열어요. (교사 화면 첫 화면에 학생 주소가 크게 나와요)

1. **게임 시작** 을 눌러요. 이때부터 배경음악과 효과음이 나와요.
2. **질문 쓰기**: 학생들이 문장틀과 예시를 보며 질문을 최대 3개까지 보내요. 위쪽 번호 동그라미로 누가 보냈는지 볼 수 있어요.
   - 장난스러운 질문은 카드의 **숨기기(눈 아이콘)** 를 눌러요. 아래 "숨긴 질문 보기"에서 다시 보이게 할 수 있어요.
3. **질문 받기 끝! 고르러 가기** → 질문 카드를 하나 눌러 고르고 **이 질문 보내기** 를 눌러요.
4. **답하기**: 학생 답이 이름 없이 카드로 쌓여요. 궁금한 카드의 **누구?** 를 누르면 "두구두구" 뒤에 번호가 나와요. **가리기**로 다시 숨길 수 있어요.
   - **답 받기 멈추기** 를 누르면 학생들이 더는 답을 고칠 수 없어요.
5. **다음 질문 고르기** 로 3~4를 반복하고, 다 끝나면 **게임 끝내기** 를 눌러요.

- 음표 버튼은 배경음악, 스피커 버튼은 효과음을 켜고 꺼요. 소리 크기는 **설정**에서 바꿔요.
- **설정**에서 학생 수, 문장틀, 예시 질문을 바꿀 수 있어요.
- **지난 기록**에서 날짜별로 질문과 답을 보고, **엑셀**로 내려받을 수 있어요. (질문 시트 · 답 시트)
- 수업 중에 교사 화면을 새로고침해도 **이어서 하기** 로 돌아올 수 있어요.

## 나중에 화면을 고칠 때
- 새 파일을 받으면 깃허브 저장소에서 **Add file → Upload files** 로 덮어 올리면 돼요.
- `config.js` 는 다시 올리지 마세요. (올리면 다시 "여기에" 상태가 돼요)
- 기록은 Firebase에 있어서 화면 파일을 바꿔도 그대로 남아요.

## 무료 사용량
- 깃허브 페이지: 공개 저장소는 무료예요.
- Firebase 무료 요금제(Spark): 하루 읽기 5만 번 · 쓰기 2만 번까지 무료예요. 수업 한 번에 쓰기 수백 번, 읽기 수천 번 정도라 충분해요.
- 한도를 넘어도 요금은 나가지 않고, 그날만 저장이 잠시 멈춰요.

## 문제가 생기면
| 증상 | 확인할 것 |
|---|---|
| 위에 "체험 모드" 띠가 계속 보여요 | config.js에 `"여기에"`가 남아 있지 않은지 (2단계) |
| "저장이 막혔어요 · 보안 규칙" 이라고 나와요 | 규칙을 붙여 넣고 **게시** 를 눌렀는지 (3단계) |
| 소리가 안 나요 | 교사 화면에서 버튼을 한 번 눌렀는지(게임 시작/이어서 하기), 음표·스피커 버튼이 켜져 있는지, 전자칠판 볼륨 |
| 학생이 번호를 잘못 눌렀어요 | 학생 화면 오른쪽 위 **번호 바꾸기** |
| Firebase에서 "보안 규칙이 안전하지 않다"는 메일이 와요 | 학생이 로그인 없이 쓰는 앱이라 오는 안내예요. 이 앱은 수업 질문과 답만 저장하고, 기록을 지우는 것은 막아 두었어요. 학생 이름이나 개인정보는 넣지 마세요. |
